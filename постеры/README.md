# Постеры событий

Положите сюда файлы праздничных постеров — эта папка имеет **приоритет** над
репозиторной `banners/` (см. `POSTER_DIRS` в `app/holidays.py`).

Имена файлов должны совпадать с каталогом праздников (`app/holidays.py`,
поле `poster`):

| Праздник            | Файл           |
|---------------------|----------------|
| Рождество           | `christmas.jpg` |
| Новый год           | `new_year.jpg`  |
| 23 Февраля          | `feb_23.jpg`    |
| 8 Марта             | `mar_8.jpg`     |
| 1 Апреля            | `apr_1.jpg`     |
| 1 Мая               | `may_1.jpg`     |
| 9 Мая               | `may_9.jpg`     |
| 1 Июня              | `jun_1.jpg`     |
| 1 Сентября          | `sep_1.jpg`     |
| 4 Ноября            | `nov_4.jpg`     |

Пока событие активно (обычно неделя), его постер применяется автоматически:

- баннер приветствия при `/start` (вместо стандартного `app/banner.jpg`);
- фото в рекламе события между видео;
- фото карточки события в пуле промо-ротации;
- фото в рассылке «событие началось».

Если файла с нужным именем нет ни здесь, ни в `banners/`, бот отправит
текст без картинки — ничего не сломается. Формат: JPG/PNG, рекомендуется
1080×1080 или 16:9, вес до 5 МБ.

## Английские постеры (`en/`)

Положите переведённую копию в подпапку `en/` той же папки —
`banners/en/mar_8.jpg` или `постеры/en/mar_8.jpg` (приоритет тот же:
сначала `постеры/en/`, затем `banners/en/`). Пользователь с языком
интерфейса «English» увидит именно её; русский получит `mar_8.jpg`.

Если английской копии нет, автоматически показывается русский оригинал —
переводить все постеры не обязательно, отсутствие файла ни на что не влияет.
То же правило работает для баннера приветствия: `app/banner_en.jpg`
подхватывается сам, без правки кода.

Расписание окон, скидки и тексты событий настраиваются в каталоге
`app/holidays.py`; отключить авто-события можно в админке:
«🎉 События» → «🤖 Авто-события: выключить».
