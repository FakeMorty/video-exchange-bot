# История Изменений (Changelog)

> ⚠️ ОБЯЗАТЕЛЬНО для любых ИИ-агентов и разработчиков: при КАЖДОМ изменении проекта добавляйте краткую запись в начало списка «## Последние изменения» ниже и обновляйте `CURRENT_VERSION` в `app/release_notes.py`. Экран «🤖 Версия бота и изменения» в боте берёт данные прямо из этого файла — не забудете записать = пользователи увидят устаревшую историю. Подробности — в `AGENTS.md`.
>
> Формат записи: одна строка `* **ГГГГ-ММ-ДД** — описание`. Без HTML-тегов (`<` / `>`), код — в backticks. Спецсимволы экранируются при выводе, но лучше их избегать.

## Последние изменения
* **2026-08-19** — Цены пакетов монет при оплате Telegram Stars скорректированы: теперь они увеличены в 3 раза относительно базового прайса; количество монет и цены DonationAlerts не изменились.
* **2026-08-19** — Цены пакетов монет при оплате Telegram Stars увеличены в 5 раз: количество монет и цены DonationAlerts не изменились; синхронизированы витрина и Mini App.
* **2026-08-18** — DonationAlerts переведён на безопасную автоматизацию: пользователь выбирает фиксированный пакет и получает одноразовый код заказа вместо передачи Telegram ID в сообщении. Автоматическое начисление теперь требует совпадения кода, точной суммы и действующего заказа; повторы платежа защищены уникальным ID. Добавлены OAuth-конфигурация, real-time подписка DonationAlerts с резервной REST-сверкой, очередь неоднозначных платежей в админке и миграция таблиц заказов/исключений. Старый открытый webhook больше не начисляет баланс по непроверенному JSON.
* **2026-08-18** — Большое упрощение пользовательского пути: исключено ИИ-общение и удалён его рабочий модуль, а пополнение монет, VIP и стили/привилегии собраны в едином разделе «🛍 Магазин». Усилена реферальная программа: приглашённый получает 20 монет на старте, пригласивший — 35 монет после трёх просмотров видео или фото, а этапные награды заметно увеличены. В «Смотреть» у администраторов появилась подтверждаемая кнопка снятия уже показанного видео или фото из ленты с уведомлением автора. При новом скрытии автора сам автор получает нейтральное уведомление без раскрытия личности блокировавшего. Добавлен разбор платёжной стратегии: Tribute исключён из-за запрета порнографического контента; целевой кандидат для автоматических платежей — ЮKassa при подтверждённой совместимости и подходящем налоговом статусе.
* **2026-08-18** — Управление блокировками стало безопаснее и удобнее: перед скрытием автора пользователь выбирает причину и подтверждает действие, после скрытия доступна мгновенная отмена. В профиле показывается счётчик блокировок, добавлены поиск по своему списку и подтверждённая массовая разблокировка.
* **2026-08-18** — В профиле появился раздел «Заблокированные авторы»: пользователь может увидеть только свой список скрытых авторов, пролистать его и безопасно разблокировать нужного автора, чтобы снова видеть его контент в ленте.
* **2026-08-04** — **Чистка репозитория и единый мастер-тест.** Удалены папки `sofa/` и `sanya/` (~32 МБ PNG-исходников стикеров) — на работу бота это не влияет: стикеры грузятся прямо из Telegram-паков (`sofa_by_Wseksbot`, `sanya_by_Wseksbot`) при старте, локальные файлы не использовались. Репозиторий похудел с ~38 до ~6 МБ. Все 32 отдельных файла тестов объединены в один большой мастер-файл `app/tests/test_bot_full.py` (помечены секции по бывшим файлам), туда же перенесены полные сценарии-сьюты (пак роста, хотфикс бонуса+поиск, уведомление о новом пользователе, ротация промо, еженедельная халява, кейсы Mini App API) — теперь тесты просто дописываются в конец одного файла: 94 теста, два прогона подряд зелёные. Попутно починены три скрытых бага тестовой инфры: общая тестовая БД переведена на файл (на `:memory:` каждое соединение пула видело свою БД), две async-фикстуры переведены с monkeypatch на гарантированный ручной откат (утекали патчи сессий в соседние тесты). `pytest.ini` больше не ссылается на несуществующий `test_db.py`.
* **2026-08-04** — **Промо-рассылки стали управляемыми + события напоминают о себе.** Авто-рассылки (бот сам пишет всем каждые 20 мин – 6 ч) переехали из кода в базу: в разделе «📣 Промо-рассылки» появился экран «📋 Авто-рассылки (ротация)» со списком всех 16 стандартных сообщений — любое можно ✏️ редактировать или 🗑 удалить, а кнопка «➕ Добавить своё сообщение» добавляет текст админа в общую ротацию (приходит наравне с остальными). Удалённые шаблоны не воскресают после редеплоя. Активные события (акции со скидками) теперь автоматически крутятся в той же ротации своими карточками (с фото, если есть) — раньше событие рассылаалось только один раз в момент создания. Событие при просмотре видео по-прежнему показывается каждые 10 просмотров. Бонусом: длинное описание события с фото больше не роняет рассылку (обрезается до лимита подписи Telegram).
* **2026-08-04** — **Фикс деплоя.** Если на Render в поле Build Command случайно оказался `bash start_render.sh` вместо `pip install -r requirements.txt`, зависимости не ставились и деплой падал с `No module named 'sqlalchemy'`. Теперь `start_render.sh` сам доустанавливает зависимости, если их не хватает (страховка от неверных настроек Render). Правильная конфигурация: Build Command `pip install -r requirements.txt`, Start Command `bash start_render.sh`. Дополнительно: merge-скрипт Neon переведён в ручной режим (запуск только с `RUN_DB_MERGE=1`) и больше никогда не затирает `bot_settings` — приветственный баннер больше не сбрасывается при деплое даже при ручном прогоне переноса.
* **2026-08-04** — **Хотфикс.** Ежедневный бонус за возвращение из-за бага в middleware начислялся повторно на каждое действие пользователя (пометка «уже начисляли сегодня» не сохранялась). Middleware исправлен; при старте теперь работает одноразовая авто-починка: лишние начисления дня вычитаются с баланса (первая выплата за сутки сохраняется, в минус не уходим, всё видно в логах баланса как `bonus_spam_repair`). Merge-скрипт миграции самоотключается после завершённого переноса (маркер `merge_completed_v1`) — раньше UPSERT из устаревшей Neon затирал более свежие данные Supabase при каждом деплое (это и сбрасывало приветственный баннер). В админке в «Управлении пользователями» добавлен поиск: частичный ник (регистр не важен) или Telegram ID — до 8 вариантов кнопками.
* **2026-08-04** — **Большой пак роста по метрикам.** Воронка оплаты: старт-пак первого платежа (500 монет за 9 Stars, строго один раз и только тем, кто ещё не платил) — показывается в магазине первым, на пэйволле «не хватает монет» и в новом «залип»-триггере: после N просмотров за день (настройка `upsell_after_views`, по умолчанию 8) юзеру прилетает персональный оффер именно в момент вовлечённости. Удержание: авто-бонус за ежедневный возврат с серией дней (стрик до 30, суммы из настроек `daily_bonus_*`), онбординг-дрип сообщений (+2ч про офферы/халяву, +26ч про рефералку, +74ч возврат в ленту, без повторов), бонус за возвращение +100 монет тем, кто неактивен 2–4 дня (не чаще раза в 7 дней). Контент: дневной лимит загрузок видео на автора (по умолчанию 100/сутки, админы без ограничений — антишум). Админка: рассылка по сегменту «ник есть, покупок 0» с готовым шаблоном и счётчиком аудитории. Новые настройки в панели: `upsell_after_views`, `comeback_bonus_amount`, `daily_video_upload_limit`, `onboarding_drip_enabled`.
* **2026-08-02** — Еженедельная халява перешла на механику секретного слова: слово недели случайно выбирается из реестра (53 слова, внутри года не повторяются), а бот **сам рассылает его всем пользователям** в день и час из настроек админки (раз в неделю, с защитой от повторной рассылки при редеплое/перезапуске). Награда за слово — случайно от 200 до 1500 монет, один раз в неделю на человека. Ввод: 🎟 Промокоды → 🎁 Еженедельная Халява. Устаревшее поле «Сумма» убрано из админки.
* **2026-08-02** — Уведомление админам «🆕 Новый пользователь» теперь приходит не на первый `/start`, а когда пользователь **впервые установил себе ник** внутри бота. Один раз: повторная смена ника и невалидные попытки админов не тревожат.
* **2026-08-02** — Починены кейсы Mini App: кнопка «Открыть» молча умирала из-за серверной ошибки (забытый `import random`), баланс в приложении отображался нулём. Заодно восстановлены кнопка «🚫 Заблокировать автора» и экран «Кейс ников» в боте (пропущенные импорты). Термины редкости из CS2 заменены на собственные: Обычная / Редкая / Эпическая / Джекпот / Золотая.
* **2026-08-01** — Завершена миграция базы данных Neon → Supabase: переписан скрипт слияния (совместимость с asyncpg/pooler, UPSERT по первичному ключу, фильтрация сиротских строк, объединение дублированных аккаунтов, досоздание недостающих таблиц и колонок по моделям). Все исторические данные — балансы, видео, фото, просмотры и логи — перенесены на новую базу.
* **2026-07-24** — Новая игра: **🚀 Космическая Аркада** — HTML5 Mini App, риск-аркада «а-ля Galaga» с растущим множителем (crash-модель как в Aviator). Игрок ставит монеты и в настоящей canvas-игре отбивает волны инопланетного флота 👾: каждая уничтоженная волна увеличивает множитель ставки, забрать выигрыш можно в любой момент, но на скрытой crash-волне флот прорывается и ставка сгорает. Все исходы считает **сервер** (crash-волна разыгрывается при старте забега и клиенту не отдаётся — накрутить выигрыш невозможно), деньги ходят только через `change_balance_atomic()`, финалы забега защищены от двойных кликов атомарными UPDATE с проверкой rowcount. Защита экономики «чтобы не сильно богатели»: лимиты ставки (10–250 монет), потолок множителя x50 с авто-выводом («сверхновая»), дневной кап чистой прибыли (500 монет), возврат ставки при «протухшем» забеге (TTL 30 мин). В админке — раздел «🚀 Аркада» (вкл/выкл, мин/макс ставки, макс. множитель, дневной кап, TTL), в боте — меню игры с WebApp-кнопкой, топ недели и пункт FAQ. Mini App обслуживается на `/arcade`, API `/api/arcade/*` проверяет Telegram `initData` (левая подпись → 401, чужой забег → 404). Добавлены миграция `arcade_runs_001` и поддержка таблицы в `fix_database()`, 26 новых тестов (математика/EV, серверное ядро, HTTP API с подписанным initData, регрессия falsy-Response).
* **2026-07-13** — Завершена система офферов и аренды: в админке появилась отдельная очередь модерации офферов и рекламных слотов с карточками, причинами отказа и уведомлениями авторов; отклонённая аренда теперь возвращает монеты, одобренная реклама реально показывается в оффере. Срок оффера начинается после одобрения и больше не игнорируется, устаревшие callback-кнопки не начисляют награды. Исправлены отсутствующие импорты/runtime-ошибки аренды и аудита подписок, добавлена строгая нормализация Telegram-ссылок и миграция метаданных модерации.
* **2026-07-13** — Обязательный нормальный ник: пользователи с ником вида `User <tg id>` (и другие placeholder/мусорные ники) больше не проходят дальше. Бот требует сменить ник. Мин. длина ника — 4 символа; запрещены `.`, `?`, пробелы, спецсимволы, ник только из цифр. Замена недопустимого ника — бесплатно.
* **2026-07-10** — Восстановлены и доработаны ключевые экономические механизмы бота:

    * **Аренда рекламных слотов**: Обычные пользователи снова могут арендовать слоты в офферах для рекламы своих каналов. Восстановлены все хендлеры аренды и проверка доступных слотов.
    * **Интерфейс создания офферов**: Добавлены шаги ввода штрафа и настройки аренды в панель администратора и пользовательский поток создания офферов.
    * **Обновление UI**: В меню офферов возвращены кнопки аренды и управления своими арендами.
