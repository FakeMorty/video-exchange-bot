# AGENTS.md — правила для ИИ-агентов и разработчиков этого репозитория

Сведения об архитектуре и запуске — в `README.md`. Ниже — обязательные процессные правила.

## 🔔 После КАЖДОГО изменения (код, фичи, багфиксы, деплой-правки)

1. **Добавь запись в `CHANGELOG.md`** — в самое начало списка `## Последние изменения`:

   ```
   * **ГГГГ-ММ-ДД** — краткое описание, что и зачем изменилось.
   ```

2. **Обнови `CURRENT_VERSION`** в `app/release_notes.py` (бампни минор/название по смыслу изменения).

Это НЕ опционально. Экран «🤖 Версия бота и изменения» в боте строится автоматически
из этих двух источников; если их не обновить, пользователи увидят устаревшую историю.

### Стиль changelog-записей
- Одна запись = одна строка, дата в `**bold**`, текст по-русски, можно со ссылками на модули в backticks.
- Без HTML-тегов и «голых» `<` / `>` (панель версии экранирует ввод, но не надо проверять её на прочность).
- Пишем с точки зрения пользы/сути, не «опять всё сломал» — changelog читают пользователи-админы.

## ✅ Перед пушем
- `python -m py_compile` по изменённым файлам.
- Запустить/дописать тесты (`app/tests/`), если правится логика, обслуживаемая тестами.

## ⚠️ Данные и секреты
- Никогда не коммитить токены, пароли БД, DATABASE_URL.
- PROD-база — PostgreSQL (Supabase). Скрипт переноса: `scripts/merge_databases.py`.
