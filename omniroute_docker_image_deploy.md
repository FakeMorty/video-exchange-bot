# 🐳 Решение проблемы «Out of Memory» при сборке OmniRoute

На бесплатном тарифе Render выделяется очень мало оперативной памяти. Из-за этого тяжелый процесс компиляции Next.js проекта (сборка из исходников) падает с ошибкой:
`Ran out of memory (used over 8GB) while building your code.`

Но у нас есть **элегантное и 100% рабочее решение профессионального разработчика**! 

Вместо того чтобы собирать проект из исходного кода, мы развернем **официальный, уже скомпилированный готовый Docker-образ**. В этом случае Render не будет ничего компилировать (это займет 0 секунд и использует 0 МБ памяти при сборке), а просто скачает готовое приложение и запустит его за 5 секунд!

Вот простая пошаговая инструкция:

---

## Шаг 1. Создаем веб-сервис из готового образа на Render

1. Зайдите в ваш личный кабинет на **Render** и нажмите на синюю кнопку **`+ New`** ➔ выберите **`Web Service`** (Веб-сервис).
2. На следующем экране выберите **второй вариант**:
   * **«Deploy an existing image from a registry»** (Развернуть существующий образ из реестра).
   * Нажмите кнопку **Next** (Далее).
3. В поле ввода **Image URL** вставьте адрес официального готового образа OmniRoute:
   ```text
   diegosouzapw/omniroute:latest
   ```
   *(Нажмите кнопку **Next**).*

---

## Шаг 2. Настройки и Переменные (Всего 3 поля!)

Перед вами откроется страница настроек. Заполните всего 3 простых поля:

1. **Name (Имя):** Напишите любое имя, например: `my-omni-gateway`
2. **Region (Регион):** Выберите **Frankfurt (EU Central)** (Франкфурт — чтобы шлюз был рядом с вашим ботом).
3. **Environment Variables (Переменные окружения):** Прокрутите страницу чуть ниже, нажмите кнопку **Add Environment Variable** и добавьте две переменные (которые вы уже умеете добавлять!):
   * **`JWT_SECRET`**: `weksim_5037_ergo_5037` *(ваш секретный ключ)*
   * **`PORT`**: `10000` *(порт запуска)*
4. Нажмите синюю кнопку **`Create Web Service`** в самом низу страницы.

---

### 🎉 И всё!
Render мгновенно (за 5 секунд) скачает готовый, оптимизированный образ и запустит его. Сборка завершится со статусом **`Live`** без каких-либо ошибок памяти! 

Вы получите ссылку на ваш рабочий шлюз (например, `https://my-omni-gateway.onrender.com`), которую укажете в настройках вашего бота в поле `AI_ASSISTANT_BASE_URL`. Бот полностью заработает!
